# 历史曲线与工艺归档

## 数据源

正常启动通过现有共享 OPC UA 会话发现 `EQ_Process`，不建立第二条 PLC 连接。连接地址仍在左下角 PLC 设置中维护。过程数组只读，节点由 BrowseName 唯一发现，不猜 namespace；必须是 Float/Double 一维数组。

点位只读加载内置 `方腔.db` 的 `ProcessDef`。Id 0～6 对应现有七条曲线，数组下标来自 Address（当前是 1～7），不是 Id。工程值不缩放、不裁剪；数据库范围不充当报警阈值。缺失定义、类型错误和重复节点会显示诊断。

每秒按本机真实时间记录一次最新有效快照。值恒定也记录；断线、订阅错误、坏质量和非法值使用 NaN，图表断线显示，不补零或以旧值冒充实时值。显式 `--simulate-alarms` 模式通过模拟设备会话提供过程值，使用正常时间并显示模拟标识，绝不自动回退模拟。

## 保存与查询

- 数据曲线：保留当前会话全量内存数据、30分钟自动跟随、手动缩放与“自动化显示”；“保存”导出当前会话全量 CSV。
- 工艺归档：上位机的全部发送／选中发送分别以 RunId 建立任务，预检通过后开始，结束处理后保存完成、启动失败、取消或异常中止状态。未通过预检不建立工艺任务；不推断外部设备自行启动的工艺。
- SQLite：`%LOCALAPPDATA%/SmallSquareCavityCoatingMachine/trend-history.db`，使用独立 ProcessRuns、ProcessSamples 表，每秒后台事务写入，保存本次定义快照和原始采样。
- 自动 CSV：同一目录下 `ProcessTrends/yyyy-MM-dd/HH-mm-ss_配方名_RunId.csv`。模拟数据使用 `trend-history.simulation.db` 与 `ProcessTrends.Simulation`。
- 工艺记录：默认查询最近7天，按任务开始日期筛选；选择任务查看，支持手动导出当前任务和导入旧格式 CSV。显示抽样保留各曲线缺失边界，存储／导出保持全量。

## 故障与恢复

记录失败持续显示红色提示，不改变配方下发／握手／停止逻辑。进程内保留工艺样本供手动导出；运行中的数据库写入会在后续采样时重试，按任务和序号幂等保存。CSV失败可通过“导出当前任务”重试。

正常退出尽量完成已接收数据的落盘；异常终止后重启，未结束记录标记为“程序中断，结束状态未确认”，不恢复执行。若磁盘持续不可用，尚未保存的内存数据会在进程退出时丢失，应尽快手动导出到可用位置。任务执行状态与记录状态分开显示，导出成功不代表数据库恢复。

## 验证

`dotnet test Tests/SmallSquareCavityCoatingMachine.Tests.csproj --no-restore`

测试包括 ProcessDef 下标与校验、每秒采样、Float/Double、质量空缺、重连、只读 OPC UA 本地回环、任务生命周期、磁盘失败、SQLite/CSV往返、断点抽样及 WPF 查询切换。UI测试只渲染离屏控件，不启动应用连接现场PLC；回环服务器只绑定127.0.0.1。现场连通性和设备量值仍需现场单独验收。
