# 配方18项绑定与逐层自动下发

## 已实现的握手

所有命令均复用设备服务的同一个OPC UA Session/Subscription。方腔.db为只读定义库，不是OPC UA服务器。

1. 固定本次待执行层快照、表格顺序、任务编号和名称；检查全部层的18项范围与PLC数值类型。选中层只执行所选层。
2. 持久化操作者、Endpoint、快照、顺序和待处理审计，然后写EQ_CoatOK=0并回读。
3. 写EQ_Recipe1前读取PLC当前完整数组，校验质量、维度、元素类型和长度；复制完整数组并用PLC实际类型覆盖0～17项，再以原长度整组写回（IndexRange为空）。18项全部回读一致后，实际写EQ_RecipeOK=0。
4. 确认本次清零后，才接受PLC的EQ_RecipeOK=1作为本层完成。有下一层回到步骤3。
5. 末层完成后由上位机写EQ_CoatOK=1，回读确认后弹窗“本次【配方名称】镀膜完成，共完成N层”。

即使首层RecipeOK原值已经是0也发送一次写0，不预写1。按用户确认，CoatOK清零不会自行启动旧参数。
任务开始前已有的1、重复1和退休会话通知不推进层号。每层独立准备监听；快速0→1可由本次清零后的有效订阅确认。
没有观察到本次0时，随后读到1也不会判作完成，结果未确认且不重试启动。

本次同步A盘最新版资源，SHA256为ec2722d62769d52ed5a67c2d2602958b32cac76abc1aefdfaa7880dd039afb3b，源文件不改写。
间隔0～120秒、镀膜0～3600秒、转速0～500rpm；其他范围来自库。气流稳定默认2秒；其他手工输入/Excel空值默认0保持不变。
手工层只校验选中控压/APC输入，但统一写满18项，未选两个值写0；Excel层保留全部18列原值。
超限、NaN、无穷大、整数节点小数或转换后超限均拒绝，不截断、不换算单位。

## 通讯、权限及异常边界

- 精确浏览BrowseName：EQ_Recipe1、EQ_RecipeOK、EQ_CoatOK；数组至少18元素；标志Boolean或严格0/1整数。没有匹配、匹配歧义、不可写或质量错误时禁止配方，但不关闭其他正常组。
- 现场EQ_Recipe1读取值为FLOAT(REAL)一维数组、长度200；配方仅覆盖0～17项，整组写入载荷必须保持PLC当前数组的类型和长度，18～199项原样保留。
- 使用整组读改写：只覆盖0～17项，保持PLC当前数组长度并保留后续元素；任何校验或整组写入失败时不降级、不重试。
- ProcessRecipe权限控制下发；任务中账号或权限丢失停止后续写入。
- 整个任务禁止切换Endpoint、重复启动、导入/新建/清除配方；切换页面不会停止任务。
- 每个短配方事务互斥参数写入。已在途参数先完成，配方最多等待15秒，等待时禁止新的参数提交；等待镀膜时仍允许ParameterSettings授权用户改参数。
- 单次通讯5秒、写后确认5秒；每层完成等待24小时。只认PLC完成标志，不用镀膜时间字段推测完成。
- 报警和报警状态未知沿用右下角提示，不新增报警配方联锁。PLC仍负责真实保护；不新增触摸屏握手或绕过联锁。
- 断线/相关点坏质量/权限丢失/退出后不续跑、不自动重试、不回滚。停止自动下发按钮不发送PLC停机命令，不代表机器已经停机。
- 未全部回读确认不清零启动；末层完成但CoatOK=1失败时显示“全部层已完成，完成标志未确认”，不弹成功提示。
- PLC已确认但最终本机记录保存失败会单独说明，不把PLC成功说成未执行。

## MVVM与追溯

- RecipeDefinitions / IRecipeDefinitionRepository：定义、显式映射、范围和类型转换。
- IOpcUaEquipmentClient / IRecipeEquipmentLease：会话代次、节点状态、整任务连接占用和短事务互斥。
- OpcUaRecipePlcGateway：写入及回读握手，逐阶段先审计；RecipeDispatchService管理执行顺序和进度。
- ProcessViewModel：命令、选择、只读快照、当前层高亮、完成/异常弹窗；XAML不读取库、不处理地址或PLC信号。
- 原Excel导入与新建层保留。导入名称取文件名去扩展名；手工名称为手工配方加开始时间。
- 独立equipment-runtime.db的Operations记录任务和各阶段，RecipeRunId关联快照与层顺序；操作历史页重启可查。
- 未结束任务重启后为“结果未确认/需人工核对”，仅恢复历史，不恢复执行。模拟使用equipment-runtime.simulation.db且标注模拟。

## 验证方式

测试替身覆盖快速/重复通知、初值0/残留1、写入拒绝、回读不一致、未确认清零、完成标志失败、权限、审计、断线、互斥和重启。
官方SDK本机服务器仅监听127.0.0.1临时端口，验证真实整组读改写/回读/层握手、末层完成标志，以及数组尾部不变和拒绝后无降级。
WPF离屏测试验证两个非连续选中层按表格顺序执行、命令禁用、当前层更新在正常负载500毫秒内、每任务一次完成提示。

```powershell
dotnet test 'Tests/SmallSquareCavityCoatingMachine.Tests.csproj' -c Release --no-restore
dotnet build 'Small square cavity coating machine.csproj' -c Release --no-restore
```

上位机确认的是约定PLC变量/完成信号，不独立证明镀膜质量或电气动作；PLC到界面总延迟需现场实测。
